# Student-Management-System
A simple Student Management System built using MySQL to manage student records, courses, and enrollments. This project demonstrates database design, CRUD operations, SQL joins, aggregate functions, and basic data analysis.
# Student Management System using MySQL

## Project Description

This project is a simple Student Management System developed using MySQL. It manages student records, course details, and enrollments using a relational database.

## Technologies Used

- MySQL
- SQL

## Database Tables

- Students
- Courses
- Enrollments

## Features

- Student Management
- Course Management
- Enrollment Tracking
- SQL Joins
- Aggregate Functions
- CRUD Operations

## Files

- student_management.sql
- sample_data.sql
- queries.sql

## How to Run

1. Run `student_management.sql`
2. Run `sample_data.sql`
3. Run `queries.sql`
